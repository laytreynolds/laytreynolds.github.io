Chadbot KB

Internal knowledge assistant for a telecom company’s sales agents, plus a public static help centre. Customer enquiries are mined from the support mailbox through a redaction pipeline with a blocking human audit, then clustered into topics that become articles. Every published article is human-approved (draft, review, approve, publish, each its own Entra role). Answers come from hybrid retrieval: pgvector and Postgres full-text fused with RRF, then reranked. Six gates sit around the model, and anything it can’t ground becomes a handover ticket, never unvalidated text. A golden set of 100 questions runs in CI against a recorded baseline.

Go · chi · PostgreSQL · pgvector · Claude · Voyage · React · TypeScript · Docker · Caddy

Chadbot

Platform for scheduled business agents on one VPS. Each agent is a Prefect flow that gathers data, calculates every figure in Python, has Claude write a little prose, and delivers the result. A validator rejects any number in Claude’s reply that isn’t in the computed figures, and the report still goes out figures-only if the model fails. The sales summariser reads a CRM through a read-only service user, checked at the start of every run, and keeps personal data away from the model. Shared encrypted credentials, a container watchdog, and a read-only FastAPI and React dashboard behind Microsoft sign-in. Direct debit failure recovery and customer outreach agents are in development.

Python · FastAPI · Prefect · PostgreSQL · Claude · React · Docker Compose · GitHub Actions
